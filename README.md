# Lab Flask

A simple Flask web application.

## Prerequisites

Make sure you have the following installed:

- Python 3.x
- pip
- Flask

Install Flask using:

```bash
pip install flask
```

## Project Structure

```
lab-flask/
│── app.py
│── templates/
│── static/
│── README.md
│── requirements.txt (optional)
```

## Running the Application

1. Open the project in VS Code.
2. Open the integrated terminal.
3. Navigate to the project directory.
4. Run the Flask application:

```bash
python app.py
```

If you're using Python 3 on Linux/macOS:

```bash
python3 app.py
```

## Access the Application

After the server starts, open your browser and visit:

```
http://127.0.0.1:5000/
```

or

```
http://localhost:5000/
```

If you're using an online IDE (such as AWS Cloud9, GitHub Codespaces, or another cloud environment), use the URL provided by the platform, for example:

```
https://<your-url>:5000/
```

## Stopping the Server

Press **Ctrl + C** in the terminal.
